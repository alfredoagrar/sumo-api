# sumo-api

API en Express para resumir textos con OpenAI (`src/`).

## Proyectos en este repositorio

- **[`clicky-clone/`](clicky-clone/README.md)**: Buddy, un clon de [Clicky](https://www.heyclicky.com/) hecho con React + Electron. Es un asistente de voz que vive junto a tu cursor, ve tu pantalla y te señala dónde hacer clic. Usa tu suscripción de Claude (Claude Code) o de ChatGPT (Codex CLI) en vez de API keys.
